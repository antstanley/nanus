## From zero to a running agent

```sh
git clone https://github.com/antstanley/nanus.git
cd nanus
cargo build --release --workspace

nanus auth set deepseek            # store a provider key (or export DEEPSEEK_API_KEY)
./target/release/nanus run "Summarise this repository."
```

The [introduction](/getting-started/introduction/) says what nanus is and why it is
built this way; the [quickstart](/getting-started/quickstart/) takes it from a fresh
clone to a named, resumable session.
